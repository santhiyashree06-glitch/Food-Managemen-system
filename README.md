# Food Management System

## Description
A Food Management System developed using Java and Spring Boot.
The application provides REST APIs for managing restaurants, food items, and food orders.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST API
- Spring Security

## Features
- Restaurant management
- Food item management
- Food order management
- Customer management
- Delivery management
- REST API integration
- Secure authentication

## Project Structure
- Model
- Controller
- Service
- Repository
- Security
